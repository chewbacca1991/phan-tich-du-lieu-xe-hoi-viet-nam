# Phân Tích Dữ Liệu Xe Hơi Việt Nam

## Giới thiệu
Ứng dụng này cung cấp phân tích chuyên sâu về dữ liệu thị trường ô tô tại Việt Nam. Chúng tôi thu thập dữ liệu từ nhiều nguồn khác nhau và sử dụng các kỹ thuật phân tích dữ liệu để cung cấp thông tin hữu ích cho người dùng.

## Tính năng
- **Trực quan hóa dữ liệu**: Các biểu đồ và bảng tổng hợp giúp người dùng dễ dàng hiểu được xu hướng thị trường.
- **Phân tích giá cả**: Thông tin chi tiết về giá cả của các dòng xe theo vùng miền và thời điểm.
- **Phân khúc thị trường**: Điều tra các nhóm khách hàng và hộ gia đình để hiểu rõ nhu cầu.

## Công nghệ sử dụng
- Python (Pandas, Matplotlib, Seaborn)
- Django cho backend
- React cho frontend

## Cài đặt
1. Clone repository: `git clone https://github.com/username/phan-tich-du-lieu-xe-hoi-viet-nam.git`
2. Cài đặt các gói phụ thuộc: `pip install -r requirements.txt`
3. Khởi động server: `python manage.py runserver`
